## Frontend Polish / Responsive Branch

### Branch: `frontend-polish-responsive`

This branch focuses on improving the frontend layout, styling, responsiveness, and basic user interaction across the React app.

Work completed in this branch:

- Improved the overall responsive layout across the frontend.
- Updated the navbar with a cleaner design and mobile-friendly menu.
- Polished the footer and footer navigation links.
- Improved listing cards on the Browse Items page.
- Improved the search/filter UI for better spacing and responsiveness.
- Updated the Item Details page layout for desktop and mobile screens.
- Fixed View Details navigation so item cards open the correct details page.
- Added scroll-to-top behavior when navigating between routes.
- Improved Login and Register page styling and inline error messages.
- Improved Report Lost and Report Found form layouts with validation feedback.
- Added a temporary feedback message for the Claim / Contact button while backend claim functionality is pending.

Backend-dependent features such as saving posts to MongoDB, claim storage, and full deployment testing are outside the scope of this branch.
