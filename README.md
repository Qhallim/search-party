## Frontend Homepage Branch

### Branch: `feature/frontend-homepage`

This branch focused on building the first version of the frontend homepage for the Lost & Found web app. My work helped set up the main user-facing landing page and gave the project its initial visual direction.

Work completed in this branch:

- Created the initial homepage for the Lost & Found frontend.
- Set up the main landing page layout using React and Tailwind CSS.
- Added project branding for the Hunter Lost & Found/Search Party concept.
- Added a hero section introducing the purpose of the app.
- Added homepage content explaining how users can browse items, report lost items, and report found items.
- Added navigation links/buttons that direct users to important pages such as Browse Items, Report Lost, and Report Found.
- Helped establish the first frontend structure before later responsiveness and polish updates were completed in another branch.

This branch mainly covers the early homepage setup. Later frontend improvements such as responsive polish, form validation, item details navigation, and button feedback were handled in the `frontend-polish-responsive` branch.
